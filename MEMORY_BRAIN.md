# MEMORY BRAIN: Английские Карточки для Android (480 слов)

Файл отслеживания архитектурных решений, этапов реализации, контекста и проделанной работы.

---

## 📌 Цель Проекта
Создать интерактивное мобильное приложение для Android (на Kotlin) для эффективного изучения 480 слов английского языка (уровни A2–B2) из Anki-колоды:
1. **Визуальное восприятие**: Черные контрастные карточки (OLED Dark Mode `#000000` / `#141418`), крупный четкий белый шрифт `#FFFFFF`, международная транскрипция IPA `#38BDF8`, практическая русская транскрипция `#94A3B8`, перевод, категория.
2. **Аудио-восприятие**: Чистое эталонное произношение носителя языка (Native American English) + разборчивый русский перевод единым голосом (*Microsoft Andrew Multilingual Neural*), с повтором 2 раза.
3. **Автоматизация и управление**:
   - Главное меню выбора тематических колод (все 480 слов + 9 категорий).
   - Кнопка **«← Меню»** в шапке экрана плеера карточек.
   - Поддержка системной кнопки "Назад" (плавный возврат в меню).
   - Автоматическое переключение карточки после 2–3 повторений (Auto-Advance).
   - Пауза / Плей, ручное листание назад (⏮️) / вперед (⏭️), немедленный повтор (🔁), тап по карточке.
   - Быстрая смена темы прямо из плеера через кнопку «Темы ▾».
   - Регулировка счетчика повторений: `2x` / `3x`.
   - Диалог завершения темы ("Повторить сначала" или "В меню тем").
4. **Брендинг и UX**:
   - Фирменный значок приложения (Adaptive Icon + PNG для всех плотностей mdpi..xxxhdpi) в темном неоновом стиле с символом «EN 480» и звуковыми волнами.
   - Анимированный экран загрузки (Splash Screen) с пульсирующим логотипом, неоновым прогресс-баром, процентами (0% -> 100%) и динамическими подсказками инициализации.
5. **Автономность**: Полная работа офлайн (все 480 карточек и 480 MP3-файлов упакованы в assets APK).
6. **Чистота репозитория**: Удалены старые тяжелые mp3 (альбомы) для подготовки к публикации на GitHub.
7. **Доставка**: Готовый APK собран (`English_Cards_480_v1.0.apk`, 28.3 MB), отправлен в Telegram и обновлен через ADB прямо на смартфоне пользователя.

### [2026-10-30 09:47 – 10:00] Исправление Произношения (Root Cause Analysis & Dual-Pass Synthesis)
- **Проблема**: Пользователь справедливо заметил, что слово «bug» звучало как «буг», а многие слова читались с корявым русифицированным акцентом.
- **Причина (RCA)**: При склеивании английского слова и русского перевода в одну фразу для TTS (`"Bug — это ошибка в программе"`), движок `edge-tts` детектировал преобладание кириллицы и переключался в русский режим, читая латиницу побуквенной русской транслитерацией (`B-U-G` -> «буг», `cat` -> «кат», `cut` -> «кут»).
- **Решение**: Разработан скрипт `generate_assets_v2.py` с технологией раздельного синтеза (Dual-Pass):
  1. Английское слово синтезируется изолированно в 100% чистом en-US режиме (`"Bug."`), активируя оригинальный словарь и фонетику американского носителя (`/bʌɡ/` -> «баг»).
  2. Русский перевод синтезируется отдельно в чистом русском режиме (`"это ошибка в программе."`).
  3. С помощью библиотеки `pydub` дорожки бесшовно склеиваются с выверенными паузами: `[English Native]` + 300ms + `[Русский перевод]` + 700ms + `[English Native]` + 300ms + `[Русский перевод]`.
- **Результат**: Все 480 аудиофайлов полностью перегенерированы. Произношение каждого английского слова стало на 100% эталонным (носитель языка), при этом сохранен единый мужской голос (Andrew).
- **Обновление**: Пересобран `English_Cards_480_v1.0.apk` (28.3 МБ), установлен на смартфон через ADB (`Success`), перезапущен на экране и отправлен в Telegram.
