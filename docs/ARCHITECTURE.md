# Архитектура приложения (Architecture Overview) v3.0

Архитектурный обзор Android-приложения EnglishCards v3.0.

---

## 1. Общая структура системы

Приложение спроектировано по принципу **100% Offline-First** и разделено на независимые слои:

```
┌────────────────────────────────────────────────────────┐
│                   UI Presentation                      │
│   MainActivity ── CardPagerAdapter ── BottomSheet      │
│   (Active Recall: Front/Prompt ── Reveal ── 4 Ratings) │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│                 FSRS & Domain Logic                    │
│   FSRSScheduler ── FSRSModels (State, Rating, Card)    │
│   (Stability, Difficulty, Retrievability, Intervals)   │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│                 Data & Storage Layer                   │
│   AppDatabase (Room SQLite) ── RoomMigrationHelper     │
│   ├── PracticeDao (practice_states)                    │
│   ├── ReviewEventDao (review_events)                   │
│   └── UserEntryDao (user_entry_states)                 │
└──────────────────────────┬─────────────────────────────┘
                           │
┌──────────────────────────▼─────────────────────────────┐
│                 Audio & Media Layer                    │
│   AudioController ── audio_manifest.json ── Assets     │
│   (Single Speech Segments, Pauses, Loop Counting)      │
└────────────────────────────────────────────────────────┘
```

## 2. Алгоритм интервального повторения FSRS (Free Spaced Repetition Scheduler)

Вместо примитивных списков и таймеров используется полноценный алгоритм FSRS (v4.5):

### Состояния карточки (`State`):
- `NEW (0)`: карточка еще ни разу не повторялась.
- `LEARNING (1)`: карточка находится на коротких внутридневных шагах запоминания (1 мин / 5 мин / 10 мин).
- `REVIEW (2)`: карточка закреплена в долгосрочной памяти, интервалы рассчитываются формулой забывания FSRS.
- `RELEARNING (3)`: повторное обучение после ошибки (`Again`).

### Оценки пользователя (`Rating`):
1. `AGAIN (1)`: «Не вспомнил» (возврат через 1 минуту, сброс стабильности, фиксация сбоя).
2. `HARD (2)`: «Трудно» (увеличение сложности, короткий интервал).
3. `GOOD (3)`: «Вспомнил» (нормальное плановое закрепление).
4. `EASY (4)`: «Легко» (бонус к стабильности, расширенный интервал).

### Предпросмотр интервалов (Interval Previews):
Перед нажатием на кнопку пользователь видит расчетное время следующего повторения (например, `< 1м`, `5м`, `10м`, `3д`), вычисляемое функцией `FSRSScheduler.preview()`.

## 3. Режим активного вспоминания (Active Recall UI)

1. **Лицевая сторона (Front):**
   - Отображается только вопрос/стимул (английский термин в режиме `EN → RU` или русский смысл в режиме `RU → EN`).
   - Ответ, перевод, педагогический разбор, код и транскрипция скрыты.
   - Большая акцентная кнопка «👁 Показать ответ» (Reveal Answer).
2. **Обратная сторона (Revealed):**
   - Раскрывается полный перевод, русская подсказка произношения, фонетическая IPA транскрипция.
   - Отображается педагогический разбор составных частей имени (например, `right` (справа) + `split` (разделить)).
   - Появляются 4 кнопки интервальной оценки FSRS с плановыми интервалами.
   - Доступны независимые кнопки озвучки: «🔊 Слово» (только термин) и «🔊 Фраза» (только контекстное предложение).
   - Кнопка «💡 Код» открывает BottomSheet с практическим кодом на Python 3.12+ / SQL / Bash.

---

## 4. База данных Room (SQLite)

- Хранение прогресса разделено по навыкам (`practice_id = "$cardId.$skill"`). Распознавание (`en_to_ru`) и воспроизведение (`ru_to_en`) имеют независимые расписания.
- Полная история каждого ответа фиксируется в `review_events` для честной аналитики эффективности обучения.
- Автоматическая миграция из SharedPreferences в Room выполняется в фоновом потоке при запуске.

---

## 5. Энергопотребление и режим экрана

- Во время активного режима обучения и воспроизведения колоды экран не тухнет (`FLAG_KEEP_SCREEN_ON`).
- При остановке, паузе или возврате в меню флаг автоматически снимается для сохранения заряда аккумулятора.
