# Документация миграции на версию 3.0 (FSRS & Room)

В данном документе описан переход проекта с монолитного JSON и локального SharedPreferences на каноническую структуру контента версии 3 (`schema_version: 3`), реляционную базу данных SQLite (Room) и алгоритм интервального повторения FSRS (Free Spaced Repetition Scheduler).

---

## 1. Изменения схемы контента (`schema_version: 3`)

### 1.1. Канонический формат
Каждая карточка теперь строго валидируется по схеме `content/schema/card.schema.json` и содержит:
- `card_id`: глобальный стабильный неизменяемый строковый идентификатор (например, `python.str.rsplit.directional`, `python.builtins.zip`, `legacy.1.enumerate`).
- `legacy_ids`: список целочисленных ID из прежних версий приложения для сохранения обратной совместимости и преемственности прогресса пользователя.
- `display_term`: отображаемый термин или вызов API.
- `meaning_ru_short`: четкий, выверенный перевод/смысл без технических артефактов и посторонних символов.
- `explanation_ru`: развернутое педагогическое объяснение (полностью устранены шаблонные фразы «ключевая сущность или архитектурный паттерн»).
- `name_breakdown`: педагогический разбор составных частей имени (например, для `rsplit()`: `right` (справа) + `split` (разделить)).
- `pronunciation`:
  - `spoken_en`: точный речевой сценарий для озвучки Andrew (`en-US-AndrewMultilingualNeural`).
  - `ipa`: проверенная фонетическая транскрипция IPA (исключены фиктивные значения вида `/rsplit/`).
  - `ru_hint`: русская подсказка к произношению без смешения латинских и кириллических букв.
- `examples`: массив контекстных примеров предложений (`example_id`, `en`, `ru`).
- `practice`: настройки активного вспоминания, шаблоны заданий, варианты ответов, cloze-пропуски.
- `technical`: проверенный рабочий сниппет на Python 3.12+ (или SQL/Bash/Git), ожидаемый вывод и ссылка на официальную документацию.
- `qa`: статус ревизии и уровень проверки (`ready`, `automated`, `model_reviewed`, `human_verified`).

### 1.2. Карта соответствия ID (`content/legacy_id_map.json`)
Все 1529 исходных числовых ID сохранены и замаплены на новые `card_id`.
Особый случай:
- Исходный ID **17 (`filter()`)** разделен на две независимые карточки:
  1. `python.builtins.filter` — встроенная функция Python.
  2. `django.queryset.filter` — метод ORM Django QuerySet.

## 2. Миграция пользовательских данных (SharedPreferences -> Room)

### 2.1. Таблицы Room
1. `practice_states`:
   - `practiceId` (PK, string, например `python.str.rsplit.directional.en_to_ru`): уникальный ключ конкретного навыка карточки.
   - `cardId`: ID карточки.
   - `skill`: направление (`en_to_ru`, `ru_to_en`, `listening`, `cloze`, `spelling`).
   - `state`: состояние FSRS (`0` = New, `1` = Learning, `2` = Review, `3` = Relearning).
   - `stability`: стабильность памяти в днях.
   - `difficulty`: сложность карточки (1.0 - 10.0).
   - `due`: время следующего повторения в миллисекундах UTC.
   - `reps`, `lapses`, `lastReview`.

2. `review_events`:
   - Журнал всех ответов пользователя: рейтинг (Again, Hard, Good, Easy), время, длительность ответа, изменения стабильности и сложности.

3. `user_entry_states`:
   - Закрепленные карточки (`isPinned`), исключенные из показа (`isSuspended`), пользовательские заметки.

### 2.2. Автоматический переход
При первом запуске обновленного приложения компонент `RoomMigrationHelper`:
1. Проверяет наличие старых ключей `card_status_<id>` в SharedPreferences.
2. Карточки со статусом `learned` переводятся в состояние `Review` со стабильностью 10 дней и интервалом 5 дней.
3. Карточки со статусом `in_progress` / `hard` переводятся в состояние `Learning` с немедленным повторением на сегодня.
4. Новые карточки инициализируются в состояние `New`.
5. Устанавливается флаг `room_migration_completed_v3 = true`.
